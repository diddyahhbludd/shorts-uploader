Privacy Policy

Shorts Uploader · Last updated November 15, 2026

Shorts Uploader ("the app") is a personal desktop tool that uploads videos to its owner's own YouTube channel. This policy explains what data the app accesses, how it is used and stored, and how to delete it.

YouTube API Services

The app uses YouTube API Services (the YouTube Data API v3). By using the app you agree to be bound by the YouTube Terms of Service. Google's use of your data is described in the Google Privacy Policy.

Information the app accesses

  • Upload access (scope youtube.upload): used only to upload video files the owner chooses, with the title, description and tags the owner provides.
  • Read-only channel info (scope youtube.readonly): used only to show the signed-in channel's name so the owner can confirm where uploads go.

The app does not access, collect or process any other YouTube or Google account data.

How information is used

Data obtained through YouTube API Services is used only to perform the upload the owner requested and to confirm the destination channel. It is not used for advertising, analytics, profiling or any other purpose.

Storage

The only thing the app stores is the OAuth sign-in token, saved as a file on the owner's own computer. The app has no server and no database. It does not store YouTube API data such as channel or video information.

Sharing

The app does not sell, share, transfer or disclose any user data to third parties. Data obtained from Google APIs is handled in line with the Google API Services User Data Policy, including its Limited Use requirements.

Cookies and tracking

The app does not use cookies, tracking pixels, device identifiers or any analytics, and does not place or read information on users' devices or browsers beyond the local sign-in token described above.

Data retention and deletion

  • The sign-in token is kept only until the owner deletes it or revokes access.
  • Deleting the token file from the computer immediately removes the app's stored data.
  • Access can be revoked at any time on the Google security settings page; after revocation the app can no longer access the account.
  • Because the app stores no YouTube API data, there is no other data to delete. Deletion requests can also be sent via the contact link below and will be handled within 7 days.

Changes

Any change to this policy will be posted on this page with a new "Last updated" date.
