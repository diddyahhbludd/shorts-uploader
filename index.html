Shorts Uploader

A personal tool that uploads the owner's own short videos to the owner's own YouTube channel.

Uses YouTube API Services

Shorts Uploader uses the YouTube Data API v3 (YouTube API Services). By using it you agree to be bound by the YouTube Terms of Service. Google's handling of your data is covered by the Google Privacy Policy.

What it does

  • Uploads videos the owner created to the owner's own channel (about one per day).
  • Reads the signed-in channel's name, only to confirm where uploads go.
  • Runs only on the owner's own computer. There is no server and no other users.
  • Does not display, store, or share any YouTube content or anyone's data.
