Privacy Policy

Last updated: November 15, 2026

Shorts Uploader ("the app") is a personal tool that uploads videos to its owner's own YouTube channel. This policy explains what data the app accesses and how it is handled.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Data the app accesses

  • Upload permission (youtube.upload): used only to upload videos the owner chose to publish.
  • Read-only channel info (youtube.readonly): used only to display the signed-in channel's name so the owner can confirm where uploads go.

Storage and sharing

The sign-in token is stored only on the owner's own computer. The app has no server, does not collect analytics, and does not sell, share or transfer any user data to third parties. Data obtained from Google APIs is used only for the purposes above, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

You can revoke the app's access at any time from your Google Account's third-party access page. Deleting the locally stored token also removes the app's access from that computer.
